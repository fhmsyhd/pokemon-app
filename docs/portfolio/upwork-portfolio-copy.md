## Project description — 498/600 characters

Designed and developed a modern Pokédex app using Kotlin, Jetpack Compose, MVVM, Hilt, Retrofit, Room, Coroutines, and Flow. I redesigned the discovery and detail experiences, added pagination, name/number search, responsive loading, empty, error, and retry states, and implemented reactive offline favorites. I also added meaningful ViewModel, mapper, and use-case tests plus GitHub Actions for test, lint, and build verification. The result is a polished, maintainable Android portfolio project.

## Overview content block

Pokédex App demonstrates how I design and structure a modern Android experience with Jetpack Compose. It combines paginated API data, search, information-rich Pokémon details, reactive local favorites, explicit UI states, and automated verification.

## Discovery caption

The discovery experience uses an adaptive grid, artwork-driven card colors, pagination, and search by Pokémon name or Pokédex number.

## Detail caption

The detail screen turns API data into a clear visual hierarchy with hero artwork, type chips, physical attributes, animated base stats, and a persistent favorite action.

## Engineering caption

The Compose UI depends on ViewModels and domain use cases. A repository coordinates PokeAPI and Room, while Kotlin Flow keeps local favorites reactive across the detail and favorites screens.
